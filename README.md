# CareerCopilot AI

This repository is being structured as a production-ready, modular full-stack AI application for resume analysis, ATS scoring, skill gap analysis, and career recommendations.

## Architecture Overview

- Frontend: React + TypeScript + Tailwind CSS
- Backend: FastAPI + Python
- Database: MongoDB Atlas
- AI/ML: spaCy, pdfplumber, sentence-transformers, scikit-learn
- Auth: JWT

## Project Structure

- frontend/: React application and UI layer
- backend/: FastAPI application and business logic
- shared/: shared schemas, types, and constants
- docs/: architecture and implementation documentation
- deployments/: deployment configuration and infrastructure assets
